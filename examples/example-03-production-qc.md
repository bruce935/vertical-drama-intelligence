# 43. Why NOT_CHECKED Matters

Incorrect:

Audio was not inspected, but no problem was noticed.

Therefore:

PASS.

Correct:

Audio evidence was unavailable.

Therefore:

NOT_CHECKED.

The system must never manufacture certainty from absence of inspection.

---

# 44. Why PASS_FOR_SCOPE Matters

A scoped production review can legitimately conclude:

PASS_FOR_SCOPE

when every requirement within the inspected scope passes.

But:

PASS_FOR_SCOPE

does not mean:

ALL PRODUCTION REQUIREMENTS PASSED.

And does not mean:

FINAL_APPROVED.

# 49. Final Rule Demonstrated

A generated scene can look technically excellent and still be wrong.

Technical quality does not override:

STORY

CONTINUITY

CANON

KNOWLEDGE

BELIEF

PHYSICAL STATE

PROP STATE

or

PRODUCTION CONTRACT.

QC must evaluate only what was actually inspected.

Therefore:

NOT_CHECKED

must never silently become:

PASS.

And:

PASS_FOR_SCOPE

must never silently become:

FINAL_APPROVED.

When output fails:

find the root cause,

correct the smallest responsible layer,

preserve passing work,

regenerate only what is necessary,

re-run the relevant QC,

and update persistent state only after approval.
