# 75. Final Rule

QC is not a confidence ritual.

It is an evidence-backed decision system.

Every PASS should answer:

WHAT WAS CHECKED?

AGAINST WHICH REQUIREMENT?

USING WHICH EVIDENCE?

Every FAIL should answer:

WHAT FAILED?

WHY DID IT FAIL?

WHERE IS THE ROOT CAUSE?

WHAT IS THE SMALLEST SAFE CORRECTION?

Every final approval should answer:

ARE ALL MANDATORY SCOPES ACTUALLY VERIFIED?

The objective is not to make the report look complete.

The objective is to prevent unverified output from being mistaken for approved production truth.
